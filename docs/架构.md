## 三、先定架构

你的架构可以这样定，不要太复杂：

```
前端：
Next.js + TypeScript + Tailwind

后端：
FastAPI + Python

智能体：
LangGraph

业务数据库：
PostgreSQL

向量数据库：
Qdrant

缓存/任务队列：
Redis

部署：
Docker Compose + Nginx
```

整体流程：

```
用户
 ↓
Next.js 前端
 ↓
FastAPI 后端
 ↓
LangGraph Agent
 ├── 比价工具
 ├── 推荐工具
 ├── RAG 工具
 ├── 风险分析工具
 └── 降价提醒工具
 ↓
PostgreSQL / Qdrant / Redis
```

你先把这个架构图画出来，哪怕用 Excalidraw 画也可以。
