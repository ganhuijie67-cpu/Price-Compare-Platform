五个 核心功能：

对，总体核心功能就这三个：

## 1. 比价

用户已经知道要买什么，比如：

```text
iPhone 17 Pro 256GB 国行
```

智能体负责调用平台工具，查询京东、淘宝、拼多多等价格，做同款匹配、价格排序、风险提示和购买建议。

## 2. 商品推荐

用户还不知道买哪款，只说需求，比如：

```text
预算 5000，想买拍照好、续航强的手机
```

智能体先分析用户需求，再结合 RAG 选购知识和价格工具，推荐合适商品，并说明为什么推荐。

## 3. RAG 问答

用户对商品、参数、平台规则有疑问，比如：

```text
256GB 够用吗？
Pro 和 Pro Max 有什么区别？
拼多多百亿补贴靠谱吗？
京东自营和天猫旗舰店有什么区别？
```

系统通过知识库检索回答，辅助用户做决策。

所以最终定位可以是：

> **一个集“商品比价 + 智能推荐 + RAG 选购问答”于一体的 AI 购物决策智能体。**





我建议只加这 **两个**，最有价值，也最能突出亮点：

## 4. 价格异常/风险提示

作用：避免智能体盲目推荐最低价。

比如某个平台价格明显低于其他平台，系统提示：

```text
该商品价格明显偏低，请确认是否为全新、国行、官方保修、是否需要用券。
```

亮点：
体现你的系统不是简单排序，而是有 **风险识别和购物决策能力**。

------

## 5. 价格历史与降价提醒

作用：用户可以设置：

```text
iPhone 17 Pro 低于 7500 元提醒我
```

系统记录历史价格，判断当前是不是好价。

亮点：
这是非常实用的功能，也能体现你会做：

```text
定时任务
缓存
数据库记录
价格趋势分析
用户通知
```

所以最终核心功能可以是：

```text
1. 商品比价
2. 商品推荐
3. RAG 问答
4. 价格异常/风险提示
5. 价格历史与降价提醒
```

这 5 个功能就已经很完整，不需要再堆太多。
